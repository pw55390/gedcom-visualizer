\# Contributing



Thank you for your interest in contributing to GEDCOM Visualizer.



\## Reporting Issues



Please use GitHub Issues to report bugs or request new features.



When creating an issue include:



\- application version

\- operating system

\- steps to reproduce

\- expected behavior

\- screenshots (if possible)



\---



\## Pull Requests



Please follow these rules:



\- use descriptive commit messages

\- keep pull requests focused

\- document new features

\- update README when necessary



\---



\## Coding Style



\- Python PEP8

\- Type hints where appropriate

\- Clear naming conventions

\- Keep functions small

\- Write reusable code



\---



\## Development



Clone repository



```bash

git clone https://github.com/pw55390/gedcom-visualizer.git

```



Install requirements



```bash

pip install -r requirements.txt

```



Run



```bash

python main.py

```
